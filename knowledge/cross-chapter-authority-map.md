## Summary

This map resolves retrieval ambiguity between the earlier top-level overview records and detailed Chapter 1–16 records. It does not replace the source-grounded records. For detailed support, retrieve the record listed in **Preferred detailed record**; use an overview only for orientation or for the stated cross-chapter synthesis.

## Agent routing rule

1. Start with the preferred detailed record when a question asks what the source says, requires a mechanism, condition, limit, procedure, or source passage.
2. Use the overview record only when it is labelled a navigation summary or cross-chapter synthesis in this map.
3. When more than one detailed record is listed, choose the record whose stated boundary matches the question; do not merge their claims without identifying that move as an inference.
4. Treat records marked **related mechanism** as complementary, not competing authorities.
